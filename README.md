# OmniNotice E2E Automation

**Playwright · Node.js · TypeScript**

Демонстрационный репозиторий сквозных (E2E) тестов для платформы OmniNotice. Проект включает в себя UI-тесты «глазами пользователя» и быстрые API-тесты.

---

## 🎥 Демонстрация

На видео показано, как автоматизация логинится, заполняет форму, нажимает «Отправить» и проверяет успешное создание рассылки (появление тоста «Рассылка успешно отправлена»).

## ✅ Статус UI-теста

На текущий момент фронтенд **успешно создаёт рассылку**. Тест проверяет полный пользовательский сценарий:

1. Закрытие онбординг-тура (если он есть).
2. Заполнение обязательных полей: «Заголовок», «Текст уведомления», «Текст кнопки», «Ссылка для кнопки».
3. Выбор приложения из выпадающего списка.
4. Открытие модального окна подтверждения и клик по кнопке «Отправить».
5. Проверка появления тоста **«Рассылка успешно отправлена»** и наличия текста уведомления в нём.

> **Историческая справка:** ранее фронтенд отправлял неверный контракт (422 Unprocessable Content) из-за отсутствия обязательных полей `event_id`, `account_id`, `recipients`, `created_at`. На момент последней проверки это поведение исправлено.

## 🚀 Как запустить локально

### 1. Установка

```bash
npm install
npx playwright install chromium
2. Настройка
Скопируйте шаблон и заполните данные:

bash
cp .env.example .env.dev
В .env.dev укажите ваш DELEGATED_TOKEN (для API) и логин/пароль (для UI).

3. Запуск тестов
bash
# Запустить UI-тест
npm run test:ui

# Запустить все тесты (UI + API)
npm test
4. Просмотр отчёта
В отчёте доступны видеозаписи каждого шага и полные логи сетевых запросов:

bash
npm run test:report
